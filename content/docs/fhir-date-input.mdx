# FHIR Date Input

The `FHIRDateInput` component handles capturing plain dates conforming strictly to the FHIR R4 \`date\` data type format (YYYY-MM-DD).

Unlike a full \`dateTime\` component, this input ensures that the value is entirely timezone-naive. This is crucial for demographics like `Patient.birthDate`, where a person's birthday remains the same calendar date regardless of the server's or browser's local timezone.

## Component API Reference

### Props

| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `string` | `undefined` | The controlled value conforming to FHIR \`date\` schema (e.g. "1990-05-15"). |
| `onChange` | `(value: string) => void` | `undefined` | Callback fired on date selection. Outputs YYYY-MM-DD. |
| `showLabel` | `boolean` | `false` | Whether to display the text label above the input. |
| `label` | `string` | `"Date"` | The text used for the label. |
| `readOnly` | `boolean` | `false` | Disables interaction with the date picker. |
