# FHIR Period Input

The `FHIRPeriodInput` component captures start and optional end bounds of a FHIR `Period` structure (e.g. `Encounter.period`, `MedicationRequest.dispenseRequest.validityPeriod`). It wraps two `FHIRDateTimeInput` fields and validates that the end time does not precede the start time.

---

## Interactive Preview

Adjust the start and end dates/times below. Entering an end timestamp preceding the start timestamp triggers an warning badge and invalidates the state.

        onChange={setPeriod}

## Key Features & FHIR Mapping

### Period Validation

If both `start` and `end` times are populated:
* The component parses and compares timestamps using absolute milliseconds.
* If `end < start`, an `"End is before Start"` badge is displayed in the header.

## Component API Reference

### Props

| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `Period` | `undefined` | Controlled value representing the FHIR `Period` object. |
| `onChange` | `(value: Period) => void` | `undefined` | Callback fired on start or end bounds modification. |
| `showLabel` | `boolean` | `false` | Displays the section header label when `true`. |
| `label` | `string` | `"Period Bounds"` | Custom section label text. |
| `readOnly` | `boolean` | `false` | Disables both inner date-time selectors. |
| `defaultOffset` | `string` | `"+07:00"` | Default timezone offset passed down to the date-time inputs. |
