# FHIR Dosage Input

The `FHIRDosageInput` component captures complex medication scheduling details and formats them into a standard FHIR R4 `Dosage` structure. Designed specifically for Indonesian **SATUSEHAT** compliance (e-prescriptions and dispensing records), it packs timing, meal relationships, route mapping, and dose quantities into a clean, horizontal row.

## Key Features & FHIR Mapping

### 1. Show Label Prop (`showLabel`)
By default, `showLabel={false}` renders only the inputs horizontally to save maximum interface space. Setting `showLabel={true}` displays helper labels above each field:
* **Seq**: Sequence ordering number (available under advanced options).
* **Frequency & Period**: Split timing input fields (e.g. `3` x `1` Day).
* **Meal Instruction**: Timing relationship dropdown (AC, PC, CC, HS).
* **Dose Quantity**: Numerical amount and unit selection dropdown.
* **Route**: SNOMED-CT pre-mapped administration route selector.
* **Instruction Text**: Editable override for the generated instruction text.

### 2. Timing Schedule
Nested FHIR timing repeat structures are handled automatically:
* **Frequency**: Mapped to `timing.repeat.frequency` (e.g. `3`).
* **Period & PeriodUnit**: Mapped to `timing.repeat.period` (e.g. `1`) and `timing.repeat.periodUnit` (`d` for day, `h` for hour, `wk` for week, `mo` for month).

### 3. Meal Relationships (`timing.repeat.when`)
Mapped to standardized HL7 event timing boundaries:
* **Before Meals (AC)** &rarr; `["AC"]`
* **After Meals (PC)** &rarr; `["PC"]`
* **With Meals (CC)** &rarr; `["CC"]`
* **Before Sleep (HS)** &rarr; `["HS"]`

### 4. SNOMED-CT Route of Administration
Pre-mapped list matching Kemenkes SATUSEHAT requirements:

| Route | SNOMED CT Code | FHIR Display |
| :--- | :--- | :--- |
| **Oral** | `26643006` | Oral route |
| **Intravenous (IV)** | `47625008` | Intravenous route |
| **Intramuscular (IM)** | `78421000` | Intramuscular route |
| **Subcutaneous (SC)** | `34246000` | Subcutaneous route |
| **Inhalation** | `30737004` | Inhalation route |
| **Topical** | `372454008` | Topical route |
| **Drops** | `46706006` | Administration of medicine by drops |

## Component API Reference

### Props

| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `Dosage` | `undefined` | Controlled FHIR R4 Dosage object. |
| `onChange` | `(value: Dosage) => void` | `undefined` | Callback fired on modification of any timing, dose, route, or text parameters. |
| `showLabel` | `boolean` | `false` | If `true`, displays field labels above each horizontal input component. |
| `readOnly` | `boolean` | `false` | If `true`, disables all input fields and selections. |
