# FHIR Religion Input

The `FHIRReligionInput` component captures patient religion mapping to the Kemenkes SATUSEHAT custom `patient-religion` extension. It outputs a fully compiled FHIR R4 `Extension` object ready to be pushed directly into the `Patient.extension` array.

## Extension Structure & Codes

The component maps user choice to a FHIR Extension payload:

* **Extension URL**: `https://fhir.kemkes.go.id/r4/StructureDefinition/patient-religion`
* **CodeableConcept System**: `http://terminology.kemkes.go.id/CodeSystem/religion`

### Religion Codes Mapping

| Code | Value Display |
| :--- | :--- |
| `1` | Islam |
| `2` | Protestan |
| `3` | Katolik |
| `4` | Hindu |
| `5` | Buddha |
| `6` | Khonghucu |

## Component API Reference

### Props

| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `Extension` | `undefined` | Controlled value representing the FHIR Extension payload. |
| `onChange` | `(value: Extension) => void` | `undefined` | Callback triggered when a new option is selected. |
| `variant` | `"toggle" \| "select"` | `"select"` | Layout variant of the input selector. Defaults to `"select"`. |
| `showLabel` | `boolean` | `false` | Displays the label above the field when `true`. |
| `label` | `string` | `"Religion"` | Label text printed if `showLabel={true}`. |
| `readOnly` | `boolean` | `false` | Locks the field and renders in disabled mode when `true`. |
