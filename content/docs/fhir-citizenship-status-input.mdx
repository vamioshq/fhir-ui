# FHIR Citizenship Status Input

The `FHIRCitizenshipStatusInput` component is a specialized selector for citizenship status codes conforming to the SATUSEHAT `citizenshipStatus` extension structure.

This component offers a modern, single-click **Toggle Group** (segmented control) variant with clean visual separation, alongside a space-saving **Select Dropdown** variant. It is designed to capture patient citizenship details for Indonesian **SATUSEHAT** patient registrations and updates.

## Citizenship Status Codes

The component maps user selection directly to SATUSEHAT citizenship status codes:

| Value Code | Display Label | Description |
| :--- | :--- | :--- |
| `WNI` | WNI | Warga Negara Indonesia (Indonesian Citizen) |
| `WNA` | WNA | Warga Negara Asing (Foreign Citizen) |

---

## Output Format

The component returns a FHIR R4 `Extension` object with the SATUSEHAT `citizenshipStatus` structure:

```json
{
  "url": "https://fhir.kemkes.go.id/r4/StructureDefinition/citizenshipStatus",
  "valueCode": "WNI"
}
```

## Component API Reference

### Props

| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `Extension` | `undefined` | Controlled value representing the citizenshipStatus Extension. |
| `onChange` | `(value: Extension) => void` | `undefined` | Callback triggered when citizenship status changes. |
| `variant` | `"toggle" \| "select"` | `"toggle"` | Layout style of the input component. Segmented button group or select dropdown. |
| `showLabel` | `boolean` | `false` | If `true`, displays the field label above the selector. |
| `label` | `string` | `"Citizenship Status"` | Custom label text rendered if `showLabel={true}`. |
| `readOnly` | `boolean` | `false` | Locks all actions and renders disabled styles if set to `true`. |
