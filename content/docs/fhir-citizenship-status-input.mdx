# FHIR Citizenship Status Input

The `FHIRCitizenshipStatusInput` component is a simple dropdown for selecting patient citizenship status (WNI or WNA).

This component returns a FHIR R4 `Extension` object with the SATUSEHAT `citizenshipStatus` structure.

## Output Format

```json
{
  "url": "https://fhir.kemkes.go.id/r4/StructureDefinition/citizenshipStatus",
  "valueCode": "WNI"
}
```

**Valid values:**
- `"WNI"` - Warga Negara Indonesia (Indonesian Citizen)
- `"WNA"` - Warga Negara Asing (Foreign Citizen)

---

## Component API Reference

### Props

| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `Extension` | `undefined` | Controlled value representing the citizenshipStatus Extension. |
| `onChange` | `(value: Extension) => void` | `undefined` | Callback triggered when citizenship status changes. |
| `label` | `string` | `"Citizenship Status"` | Custom label text. |
| `description` | `string` | `undefined` | Additional helper text displayed below the label. |
| `placeholder` | `string` | `"Select citizenship status"` | Select placeholder text. |
| `readOnly` | `boolean` | `false` | Disables the input if set to `true`. |
