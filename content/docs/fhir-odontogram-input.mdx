# FHIR Odontogram Input

The `FHIROdontogramInput` component captures dental chart (Rekam Medis Gigi) data conforming to the **SATUSEHAT** FHIR R4 implementation guidelines.

FHIR doesn't natively have an "Odontogram" resource. SATUSEHAT models dental records using an array of `Observation`, `Condition`, and `Procedure` resources, with each action explicitly tied to a `bodySite` using SNOMED CT codes representing specific teeth (FDI notation).

You interact visually with a chart of 32 permanent and 20 deciduous teeth, and the component dynamically generates a list of strict FHIR Resources.

## Key Features & FHIR Mapping

### Key Features

#### Interactive SVG Dental Chart

- **32 Permanent Teeth** + **20 Deciduous Teeth** displayed using FDI two-digit notation
- **Visual Condition Mapping** with color-coded markers for common dental conditions
- Click-to-add interaction for quick data entry

#### Supported Dental Conditions

| Condition | SNOMED CT | Description |
| :--- | :--- | :--- |
| Caries | `274899004` | Dental caries (karies gigi) |
| Missing | `274768008` | Missing tooth (gigi tanggal) |
| Crown | `242458000` | Crown restoration (mahkota tiruan) |
| Sealant | `414151009` | Pit and fissure sealant (sealant) |
| Amalgam | `282514008` | Amalgam restoration (tambalan amalgam) |
| Composite | `282449005` | Composite restoration (tambalan komposit) |
| Root Canal | `282507008` | Root canal treatment (saluran akar) |

#### FHIR Resource Generation

Each tooth action generates appropriate FHIR resources:

- **Condition** for clinical findings (Caries, Missing)
- **Procedure** for treatments performed (Extraction, Restoration)
- **Observation** for assessments (Tooth mobility, Periodontal status)

## Component API Reference

### Props

| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `any[]` | `[]` | Array of FHIR Resources (`Condition`, `Procedure`, `Observation`) representing the chart state. |
| `onChange` | `(resources: any[]) => void` | `undefined` | Callback fired when a new resource is generated. |
| `readOnly` | `boolean` | `false` | Disables interactivity, transforming the component into a read-only visualizer. |
