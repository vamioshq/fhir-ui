# FHIR Odontogram Input

The `FHIROdontogramInput` component captures dental chart (Rekam Medis Gigi) data conforming to the **SATUSEHAT** FHIR R4 implementation guidelines.

FHIR doesn't natively have an "Odontogram" resource. SATUSEHAT models dental records using an array of **`Observation`** resources with the clinical term code `OC000061` ("Pemeriksaan Odontogram"), where each action is explicitly tied to a tooth in `bodySite` using SNOMED CT concepts and detailed in `component` sub-structures.

You interact visually with a chart of 32 permanent and 20 deciduous teeth, and the component dynamically generates a list of strict FHIR Resources.

## Key Features & FHIR Mapping

### Key Features

#### Interactive SVG Dental Chart

- **32 Permanent Teeth** + **20 Deciduous Teeth** displayed using FDI two-digit notation
- **Visual Condition Mapping** with color-coded markers for common dental conditions
- Click-to-add interaction for quick data entry

#### Supported Dental Conditions

| Condition | SNOMED CT | Description |
| :--- | :--- | :--- |
| Caries | `64228005` | Dental caries (karies gigi) |
| Amalgam | `37731006` | Amalgam filling (tambalan amalgam) |
| Composite | `278142004` | Composite filling (tambalan komposit) |
| Crown | `105570003` | Dental crown (mahkota tiruan) |
| Missing | `109675001` | Missing tooth (gigi tanggal) |
| Root Canal | `394770001` | Root canal therapy (perawatan saluran akar) |
| Sealant | `61022005` | Dental sealant (sealant gigi) |
| Radix | `370962002` | Retained tooth root (sisa akar) |
| Unerupted | `109677009` | Unerupted tooth (gigi belum tumbuh) |
| Fracture | `312351000` | Fracture of tooth (fraktur gigi) |
| Bridge | `448275005` | Dental bridge construction (jembatan gigi) |

#### FHIR Resource Generation

Each tooth action strictly generates a SATUSEHAT-compliant `Observation` resource:

- **`Observation.code`**: `OC000061` ("Pemeriksaan Odontogram") under `http://terminology.kemkes.go.id/CodeSystem/clinical-term`
- **`Observation.bodySite`**: Mapped to the specific tooth's SNOMED CT structure code.
- **`Observation.component`**:
  - `surf` (Permukaan gigi): value from Kemenkes dental-surface system (`O`, `M`, `D`, `V`, `L`, `R`). Omitted for whole-tooth conditions.
  - `cond` (Keadaan Gigi): clinical finding SNOMED CT code.

## Component API Reference

### Props

| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `any[]` | `[]` | Array of SATUSEHAT-compliant `Observation` resources representing the chart state. |
| `onChange` | `(resources: any[]) => void` | `undefined` | Callback fired when a new resource is generated. |
| `readOnly` | `boolean` | `false` | Disables interactivity, transforming the component into a read-only visualizer. |
