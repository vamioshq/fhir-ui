# FHIR Birth Place Input

The `FHIRBirthPlaceInput` component is a specialized input for capturing patient birth place information. It uses a free text input for the city name with a country dropdown (Indonesia / Luar Negeri).

This component returns a FHIR R4 `Extension` object with the SATUSEHAT `birthPlace` structure. For foreign births, the `country` field is omitted from `valueAddress`.

## Output Format

### Indonesia Birth Place

When "Indonesia" is selected:

```json
{
  "url": "https://fhir.kemkes.go.id/r4/StructureDefinition/birthPlace",
  "valueAddress": {
    "city": "Bandung",
    "country": "ID"
  }
}
```

### Foreign Birth Place (Luar Negeri)

When "Luar Negeri" is selected, the `country` field is omitted from `valueAddress`:

```json
{
  "url": "https://fhir.kemkes.go.id/r4/StructureDefinition/birthPlace",
  "valueAddress": {
    "city": "Singapore"
  }
}
```

## Component API Reference

### Props

| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `Extension` | `undefined` | Controlled value representing the birthPlace Extension. |
| `onChange` | `(value: Extension) => void` | `undefined` | Callback triggered when birth place changes. |
| `label` | `string` | `"Birth Place (Tempat Lahir)"` | Custom label text. |
| `description` | `string` | `undefined` | Additional helper text displayed below the label. |
| `placeholder` | `string` | `"e.g., Bandung, Singapore, etc."` | Input placeholder text. |
| `readOnly` | `boolean` | `false` | Disables the input if set to `true`. |
