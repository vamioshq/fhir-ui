# FHIR Vital Signs Input

The `FHIRVitalSignsInput` component parses and captures standard physiological vital sign measurements conforming to the FHIR R4 standard (`Observation`).

This component supports direct configuration presets mapping each input field to standard LOINC codes and UCUM units, automatically validating clinical limits, and auto-calculating BMI. It can be rendered as a unified vital signs entry panel, or as individual inputs for specific measurements.

---

## Interactive Preview

### Individual Input Previews

You can render specific vital sign fields individually by passing the `preset` prop. This locks the input to the target metric and directly generates the appropriate FHIR `Observation` payload, omitting all other fields.

#### Blood Pressure Preset (`preset="blood-pressure"`)

Captures both systolic and diastolic blood pressure side-by-side:

<ComponentPreview 
  component="fhir-vital-signs-input" 
  example="blood-pressure-preset"
  code={`import React from "react";
import { type Observation } from "@medplum/fhirtypes";
import { FHIRVitalSignsInput } from "@/registry/fhir-ui/fhir-vital-signs-input";

export default function BloodPressureForm() {
  const [observations, setObservations] = React.useState<Observation[]>([]);

  return (
    <FHIRVitalSignsInput
      preset="blood-pressure"
      value={observations}
      onChange={setObservations}
    />
  );
}`}
>
  <FHIRVitalSignsInputDemo />
</ComponentPreview>

### Key Features

#### SATUSEHAT System & LOINC Presets
The individual inputs inside this component leverage self-contained vital signs presets, pre-configured with standard LOINC codes, UCUM units, and built-in validation thresholds:

| Preset Name (`preset`) | LOINC Code | UCUM Unit | Standard Validation / Thresholds |
| :--- | :--- | :--- | :--- |
| `systolic` | `8480-6` | `mm[Hg]` | Normal: `90-119`. Pre-High: `120-139` (Amber). High: `≥ 140` (Red). |
| `diastolic` | `8462-4` | `mm[Hg]` | Normal: `60-79`. Pre-High: `80-89` (Amber). High: `≥ 90` (Red). |
| `blood-pressure` | `85354-9` | `mm[Hg]` | Composite group of both Systolic and Diastolic side-by-side. |
| `heart-rate` | `8867-4` | `/min` | Normal: `60-100 bpm`. Low: `< 60` (Red). High: `> 100` (Red). |
| `temperature` | `8310-5` | `Cel` | Normal: `36.0-37.5 °C`. Hypothermia: `< 36.0` (Red). Fever: `> 37.5` (Red). |
| `respiratory-rate` | `9279-1` | `/min` | Normal: `12-20 bpm`. Low: `< 12` (Red). High: `> 20` (Red). |
| `spo2` | `2708-6` | `%` | Normal: `≥ 95%`. Low/Hypoxia: `< 95%` (Red). |
| `height` | `8302-2` | `cm` | Physical height. Validation boundary: `30 - 250 cm`. |
| `weight` | `29463-7` | `kg` | Physical body weight. Validation boundary: `1 - 300 kg`. |
| `height-weight` | - | - | Composite height & weight side-by-side. Displays calculated BMI badge. |
| `waist-circumference` | `8280-0` | `cm` | Central Obesity: Men `≥ 90 cm`, Women `≥ 80 cm`. |

#### Real-Time Validation
When a value is entered, the input checks standard bounds on-the-fly and projects a validation label next to the input title. 

#### Auto-Calculated BMI
When height and weight are provided (and `preset` is omitted to show the full panel), the component automatically calculates the Body Mass Index (LOINC `39156-5`) and outputs a SATUSEHAT-compliant BMI observation containing a categorization badge (Underweight, Normal, Overweight, Obese).

## Component API Reference

### Props

| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `Observation[]` | `[]` | Array of controlled FHIR Observation resources. |
| `onChange` | `(value: Observation[]) => void` | `undefined` | Callback fired on value or metadata modification, returning the complete list of observations including calculated BMI. |
| `patientId` | `string` | `"patient-1"` | Subject Patient reference ID for generated FHIR resources. |
| `encounterId` | `string` | `"encounter-1"` | Context Encounter reference ID for generated FHIR resources. |
| `readOnly` | `boolean` | `false` | Sets all input fields to read-only mode and disables interactions. |
| `preset` | `VitalSignsPreset` | `undefined` | Target vital sign preset to render individually. If omitted, the full panel is rendered. |
| `patientGender` | `"male" \| "female"` | `undefined` | Optional patient gender to drive gender-specific validation presets (like waist circumference). |
